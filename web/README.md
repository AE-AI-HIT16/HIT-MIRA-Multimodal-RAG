# web/ — Frontend (Next.js)

Chatbot web app cho HIT-MIRA (BR-500): khung chat, upload ảnh, render kết quả
đa phương thức (ảnh + clip + link), màn hình admin (nạp dữ liệu, pipeline, đánh giá).

Khởi tạo (khi bắt đầu làm frontend):

```bash
npx create-next-app@latest . --ts --app
```

Module chính dự kiến: `chat/`, `media-viewer/`, `admin/`, `lib/api-client`.
